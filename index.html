The Problem

Current HCI relies on physical peripherals, creating friction for presenters, surgeons, musicians, and people with motor disabilities.

This problem was treated heartly by our team.
We built a system that listens to your body — not your keyboard.

Architecture & Solution

🧠
Backend Intelligence
Real-time hand landmark extraction at 30 FPS. Each frame produces a compact 126-value keypoint vector — no raw image processing.
PythonMediaPipe OpenCVNumPy
⚡
Dual-Model Logic
Static poses use a Dense/Conv1D network (instant). Motion gestures use a 3-layer LSTM reading 30 consecutive frames via a sliding window.
TensorFlowKeras LSTMConv1D
🖥️
OS Execution Layer
Gestures map to real OS commands — tab switching, volume control, keyboard shortcuts — executed natively via PyAutoGUI and Pycaw.
PyAutoGUIPycaw pygetwindowcustomtkinter
MediaPipe · 21 landmarks · 126-dim vector · TensorFlow/Keras · Dense · Conv1D · LSTM · PyAutoGUI · Pycaw · ONNX · Hugging Face
Static Gesture: fist · open_palm · peace  ·  Motion Gesture: swipe_left · swipe_right · circle  ·  Chrome · VS Code · Spotify
Confidence 0.9 (static) · 0.8 (motion) · 30-frame sliding window · EarlyStopping patience=50 · Adam optimizer

Setup & Installation

01
Clone the Repo
git clone https://github.com/YOUR_USERNAME/gesture-io

Windows 10/11 required for OS-level controls.

02
Python 3.10 + venv
pip install -r requirements.txt

TensorFlow, MediaPipe, OpenCV, pyautogui, pycaw, customtkinter.

03
Download Tasks
python setup.py --download-tasks

Downloads MediaPipe task files & model weights from Hugging Face.

04
Run
python main.py

Desktop GUI launches. Both models run simultaneously in real time.

30-frame sliding window · LSTM motion recognition · dual-model architecture
